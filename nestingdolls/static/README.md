# Static files

This is the ordinary Django static-files home for `nestingdolls`. Most of the
package does its work on the server, but a sequence field is more pleasant to
use when the browser can add and remove its own rows without asking for a whole
new page. The assets for that small bit of browser work live here.

There should not be much to see at this level. It is the boundary between the
package's Python code and the browser-facing files beneath it.

Further documentation is available within [nestingdolls/README.md](./nestingdolls/README.md)
