{% load i18n %} {% comment %} A host page already has its own way to show a message: a toast library, a live region, or something else. This widget must not force one choice on every page that uses it. So the script fires a bubbling `nestingdolls:sequence-change` event instead, after it adds or removes a row. The host page can listen for the event and show its own message. Do not add a status element here again: see README.md. {% endcomment %}
